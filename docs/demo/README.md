# Demo recording

The [README demo section](../../README.md#demo) links to the public
[September 3 demo recording](https://github.com/adrithk/Resale-Automator/releases/tag/demo-2026-09-03).
The approximately one-minute MP4 shows photo intake, listing review, CSV export,
and manual Depop import ending in a draft with photos.

The video is a GitHub release asset, not a large file in Git history. This
demo-only release is not an application version. The original MOV is unchanged;
the public copy is an MP4 converted with macOS's default metadata filtering.
To replace it later, upload a new release asset and update the README link.

## Suggested walkthrough

1. Show the local app and select two garment photos plus a readable tag.
2. Analyze and review the clothing fields.
3. Review/edit the generated text and price.
4. Approve and save; download the CSV with hosted photo links.
5. In your normal Depop browser, import the CSV and show the resulting draft.
6. Explain that publishing is manual while Selling API access is being pursued.

Hide API keys, .env contents, addresses, account details, notifications, and
private file paths. Use clothing photos you own and want to make public. Do not
show the terminal or saved-listing path if it reveals personal information.
